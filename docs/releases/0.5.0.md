# v0.5.0 — 图片预览与内容操作

## 新增

- 发送图片和接收完成后的图片显示本机缩略图，传输记录可复制原尺寸图片。
- 传输记录显示文本正文和换行，支持复制文本；其他文件可打开所在文件夹。
- 收件弹窗支持文本复制、图片另存为；继续使用宿主自绘文件树。选择保存位置不提前接收，确认接受后才开始保存。
- 默认接收目录为 `~/Download/OToolsLocalSend`（Download 单数）；保留自定义目录和旧文件。
- 打开插件页面、宿主桥就绪后自动启动已停止的服务一次；已运行不重复启动，手动停止后当前页面不被轮询重新拉起。

## 修复与保护

- 下载目录在服务启动/重启时正确展开主目录。
- 文件落盘使用原子防覆盖与唯一命名，历史记录只指向实际完成的文件；失败/取消中的成功文件仍保留。
- 图片预览校验格式、尺寸、内存工作区和输出大小，拒绝对端网址、解压超限或不一致的内部图片帧。
- 复制和文件夹操作等待宿主结果，失败不误报成功；图片临时复制资源正确释放。
- 保留明亮默认、宿主明暗主题同步、手动启停、LocalSend v2 官方线格式与流式文件传输。

## 使用说明

标准 LocalSend 图片在确认前只有元数据，弹窗显示“接受后显示预览”，不会为了预览自动接收。
PNG/JPEG/GIF/WebP/BMP 支持有界本机预览；超限、损坏和复杂 WebP 格式会关闭预览/图片复制，但仍可作为普通文件传输。
旧发送记录没有本机源路径，无法恢复定位或复制原图；不会猜测路径或迁移旧文件。
自动启动以新页面加载为周期；宿主只是隐藏再显示既有页面时，保留该页面内的手动停止状态。
